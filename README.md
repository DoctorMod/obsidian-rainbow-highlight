# Highlightr-Plugin

![Rainbow Highlight Downloads](https://img.shields.io/github/downloads/DoctorMod/obsidian-rainbow-highlight/total.svg)
![Rainbow Highlight Releases](https://img.shields.io/github/v/release/DoctorMod/obsidian-rainbow-highlight)

I really like highlighting my notes when I use obsidian, but a lot of the plugins out there that do this sort of thing, are a bit clunky and don't have the ease of use that i feel i want, where i can just use a keybind and it will go up in rainbow order. Specific I know, but that's how i like it!

All you need to do after you install it is use the obsidian in build highlight tag `==` around some text and it will be highlighted in some fun colours, going up in rainbow order.

## Pre-Release Disclaimer

Just note that this is in pre-release stages right now, so it's still pretty buggy a lot of the time, because new lines, formatting and anything else you place inside the highlighted text will break it all currently.

## Installation

This plugin is currently not available on the obsidian plugin store, but If i iron out enough of the bugs, then I'll probably publish it there.

Manual installation is as follows:
1. Open your obsidian plugin folder (go to Community Plugins > Installed Plugins > 📂)
2. Create a new folder `Rainbow Highlight`
3. Copy the files from Latest Release into that folder
4. Reload Obsidian and enable the plugin
